# OSFIT 0.1.0 — первая функциональная сборка

OSFIT — автономный PWA-трекер тренировок на React 19, TypeScript и Vite. Хранение в IndexedDB, без регистрации и бэкенда.

## Важное замечание об исходной базе

Это **самостоятельно подготовленная первая сборка на стеке lyftr**, а не буквальный GitHub fork и не копия его репозитория: полное скачивание оригинала во время подготовки оказалось недоступно. Структура и набор функций построены с опорой на анализ файлов `web/src/App.tsx`, `web/src/pages/ActiveWorkout.tsx`, `web/src/pages/Programs.tsx`, `web/src/services/api.ts`, `web/src/components/Layout.tsx`, `web/package.json` из Cawlumm/lyftr. Чужой код этих файлов в поставку не копировался. Для настоящего форка требуется отдельно перенести исходный репозиторий.

## Запуск

1. `npm install`
2. `npm run dev`
3. `npm run build` — production-сборка
4. `npm run preview` — просмотр сборки

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `osfit`.
2. Загрузите содержимое **этой папки** в корень репозитория (не сам ZIP как один файл).
3. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. После загрузки в `main` запустится `.github/workflows/deploy.yml`.
5. Открывайте адрес, который GitHub отобразит на странице Pages.

В Vite используется относительный `base: './'`; это совместимо с подкаталогом GitHub Pages при одностраничной навигации без прямых серверных маршрутов.

## Что работает

- Создание, редактирование, удаление, копирование программ.
- Выбор упражнений из каталога или создание собственного.
- Список подходов, ввод веса и повторений, отметки выполнения.
- Ручное завершение и сохранение сессии.
- Предупреждение о несохранённых изменениях при навигации и попытке закрыть вкладку (ограничено поведением браузеров).
- История с подробностями и удалением тренировок.
- Суммарный тоннаж, выполненные подходы, рекорды по оценке 1ПМ Эпли.
- IndexedDB, экспорт JSON, восстановление архива OSFIT 0.1.0.
- PWA и офлайн-кеш браузерных ресурсов.

## Не входит в 0.1.0

Импорт тренировочных программ TXT/CSV/XLSX, импорт старых JSON Scriptable IRONLOG, отдельная карта мышц, календарь, замеры, расширенные графики и рекомендации прогрессии. Эти функции запланированы на следующие этапы.

## Ограничения

- Архив JSON содержит данные OSFIT 0.1.0. Импорт заменяет локальную базу.
- При удалении данных сайта история будет утрачена, если не создана резервная копия.
- Гарантировать предупреждение при принудительном закрытии iOS-приложения невозможно.
- SVG иконка PWA является временной. Для максимальной совместимости iOS желательно добавить PNG 192×192 и 512×512.
- `npm install` и production-сборка должны быть проверены на машине или в GitHub Actions с доступом к npm; в среде подготовки доступ к реестру пакетов отсутствовал.
