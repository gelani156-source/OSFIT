# OSFIT 4.9 — исправления упражнений и истории

Обновление на основе исходников OSFIT 4.8/4.7. Установка: скопируйте **содержимое архива** в репозиторий OSFIT, не в Stack. Настройки GitHub Pages: GitHub Actions.

Изменения: подсчёт мышечных групп в истории и импортированных тренировках IRONLOG; интервалы 7, 30, 90, 365 **календарных дней**; сохранение незавершённой тренировки как черновика и восстановление её из полной резервной копии вместе с программами, историей, замерами, расписанием, профилем и силовыми целями.

Скручивания/пресс без веса; подтягивания и отжимания с необязательным **дополнительным** весом; «косичка» — кроссовер с канатом, «трицепс» — кроссовер с прямым грифом. Для разгибаний в кроссовере вводится количество **плиток по 5 кг**. В расчёте тоннажа плитки умножаются на 5, упражнения без веса дают 0 кг тоннажа, но учитываются в подходах.

Вариант «Сохранить и выйти» и автоматический черновик доступны в тренировке; возвращайтесь кнопкой «Продолжить незавершённую тренировку». При экспорте резервной копии необходимо убедиться, что файл действительно сохранён в «Файлы».

⚠️ Проверка: в данной среде полную сборку `npm run build` завершить не удалось — отсутствуют зависимости React/Vite. Код публикуется как исходный пакет для сборки через GitHub Actions, а не как подтверждённый production build. Перед заменой сделайте копию данных.
