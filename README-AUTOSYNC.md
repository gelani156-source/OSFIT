# OSFIT 5.1 — автоматическое обновление Scriptable

**Важно:** автоматический обмен требует собственного Cloudflare Worker + KV. GitHub Pages и Scriptable не имеют доступа друг к другу через локальную IndexedDB. Ручной импорт JSON больше не требуется после однократного подключения.

1. В Cloudflare Workers & Pages создайте Worker и вставьте содержимое `worker/index.js`.
2. Создайте KV namespace и добавьте binding **WIDGET_DATA** к Worker.
3. В настройках Worker добавьте **секрет** `SYNC_TOKEN` — длинный случайный ключ (не публиковать).
4. Deploy. Получите `https://...workers.dev`.
5. В OSFIT → Настройки → Автосинхронизация виджета введите URL и тот же ключ.
6. В Scriptable создайте `OSFIT Widget Auto`, вставьте `OSFIT_Widget_Auto_Scriptable.js` и запустите вручную один раз для URL/ключа.
7. Добавьте виджет Scriptable на главный экран и выберите `OSFIT Widget Auto`.

После изменения подходов OSFIT публикует обновлённый снимок при наличии интернет-связи и открытого приложения. Scriptable загружает снимок при обновлении виджета, периодичность которого контролирует iOS. Нельзя гарантировать мгновенную смену виджета. Поддерживается пауза тренировки: сохраняется черновик. На сервер отправляются только название, дата, упражнения, веса, повторы и флаги выполнения — без медицинских данных, замеров и остальных целей.

**Безопасность:** работайте только по HTTPS, не делитесь секретом `SYNC_TOKEN`. URL и ключ хранятся локально в OSFIT/Scriptable, а информация о тренировках — в выбранном вами Cloudflare KV в виде JSON. Для полной приватности без внешнего сервера фоновая синхронизация невозможна.
