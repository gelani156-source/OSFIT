OSFIT 4.7 — ПОЛНЫЙ ИСХОДНЫЙ ПРОЕКТ (GitHub Pages)

Этот архив объединяет полный комплект OSFIT 4.3 (включая светлую/тёмную тему, мини-панель тренировок и исходники iOS WidgetKit) и последние переданные App.tsx и db.ts версии 4.7.

УСТАНОВКА:
1. В открытом OSFIT экспортируйте резервную копию JSON.
2. Распакуйте ZIP. Замените содержимое репозитория GitHub всеми файлами и папками из архива, сохранив пути (особенно src/, public/, .github/workflows/).
3. Не удаляйте старую базу браузера и не очищайте данные Safari.
4. Запустите GitHub Actions / deploy и убедитесь, что npm ci и npm run build завершаются успешно.
5. Проверьте приложение на iPhone: темы, 3 режима, сохранение/восстановление черновика, мышечную карту за 7/30/90/365 дней, историю, импорт и резервные копии.

ПРОВЕРКА В СРЕДЕ ПОДГОТОВКИ:
- Синтаксис исходных TS/TSX проверен глобальным TypeScript transpileModule (ошибок нет).
- Проверены локальные относительные импорты (неразрешённых путей нет).
- Полный tsc -b / vite build НЕ выполнен: необходимые npm пакеты недоступны, registry.npmjs.org не разрешается в среде.
- Работоспособность в Safari/на iPhone не подтверждена.
- iOS_WidgetKit_SOURCES — исходники для отдельного нативного iOS-проекта, не готовый виджет домашнего экрана.

ПРЕДУПРЕЖДЕНИЕ: Не повторяйте импорт истории из IRONLOG без необходимости — возможны дубли.
