# OSFIT 5.2 — ревизия логики

Основа: исходный комплект OSFIT 5.1 AutoWidget.

## Изменено
- Сводка по группам и анатомический атлет используют один классификатор упражнений (`src/MuscleMap.ts`).
- Основная группа получает полные подходы; вторичные мышцы получают 0,35 условного подхода **только в анатомической карте**. Сводка по группам считает подходы только по основной группе.
- Жим и отжимания классифицируются как грудь (передние дельты/трицепс вспомогательно); косичка и разгибания рук — трицепс; отдельные три дельты; подтягивания/тяги — спина; упражнения на ноги разделены.
- Старые импортированные завершённые тренировки с полностью отсутствующими done-флагами учитываются по числу повторений. Риск: запланированные подходы старого импорта могут попасть в статистику.
- Восстановление старых архивов, где нет strengthGoals, больше не стирает текущие цели по умолчанию.
- Обновлены иконки для iOS и манифест, версия Service Worker.

## Остающиеся ограничения
- Данные OSFIT физически на iPhone не проверены. Cloudflare Worker требует пользовательской настройки; автоматического локального фонового доступа Scriptable к IndexedDB нет.
- Прямой запуск/публикация GitHub Pages не выполнялись. Полная npm-сборка не проверена из-за недоступности зависимостей в среде.
- Для гарантированного сохранения данных перед обновлением нужен экспорт JSON-бэкапа существующей версии и проверка файла.
