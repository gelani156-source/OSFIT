OSFIT 4.0 — сборка-кандидат, 30.10.2026

Это исходные файлы для загрузки на GitHub. НЕ подтверждено успешной сборкой npm: зависимости React/Vite отсутствуют в рабочей среде.

ИЗМЕНЕННЫЕ ФАЙЛЫ:
  src/App.tsx
  src/smart.ts  (НОВЫЙ, обязателен)

Поставляется также полный комплект конфигурации из OSFIT 3.0.

Что доступно в текущем кандидате:
- Компактный режим подходов и скрытие дополнительных параметров
- Сортировка завершённых упражнений вниз и их сворачивание
- Отмена изменения подхода в активном редакторе
- Подбор упражнений по мышечным группам и замена на аналоги
- Предыдущие результаты и базовая рекомендация веса
- Готовые шаблоны Full Body / Upper-Lower / Push-Pull-Legs / сплит / сила / A-B
- Импорт/экспорт программы в JSON
- Перенос активной тренировки в JSON, импорт TXT/CSV/XLSX из предыдущего обновления
- Сравнение тоннажа двух тренировок, цели по расчётному 1ПМ
- Недельные рабочие подходы по мышечным группам, дата последнего экспорта
- Женский/мужской атлет, исправление подсветки икр (в App.tsx)

НЕ завершено/не протестировано полностью:
- Полноценный адаптер для любого стороннего фитнес-приложения
- Полноценная последовательная автоматизация цикла A/B/C
- Полный расчёт мышечного баланса с визуализацией и распределением вспомогательной нагрузки
- Надёжное распознавание всех неоднозначных записей: сейчас приложение предупреждает и предлагает предварительную замену, требующую проверки
- Полные end-to-end тесты и проверка компиляции со всеми npm зависимостями

УСТАНОВКА:
1. Сохраните резервную копию данных из работающей версии OSFIT прежде чем обновлять.
2. В GitHub замените src/App.tsx на новый, создайте src/smart.ts.
3. Сохраните остальные файлы существующего проекта без замены, если текущая сборка работает.
4. Откройте Actions: если есть ошибка, отправьте журнал ошибки.
5. После успешного развёртывания проверьте сохранение/восстановление истории, импорт, тренировки, карту и календарь.
