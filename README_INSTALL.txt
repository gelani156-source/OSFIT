OSFIT 4.2 — единый пакет для GitHub Pages.
1. Сохраните полный архив текущих данных OSFIT в настройках.
2. Распакуйте архив и замените содержимое репозитория соответствующими файлами с сохранением структуры папок (src/*, public/*, package.json и др.).
3. GitHub Actions -> Build/deploy.
4. Очистите кеш PWA или перезапустите установленное приложение, если старая версия не обновилась.
5. Проверьте три режима тренировки, тумблер темы, импорт, историю, рекорды.
Существующие записи IndexedDB не удаляются при замене файлов.
Проверка TypeScript выполняется в GitHub Actions.
