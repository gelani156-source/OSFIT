На вкладке «Тренировка» появляется мини-панель при наличии локального черновика.
В редакторе текущей тренировки отображается та же панель.
Нажатие на галочку отмечает ВСЕ подходы выбранного упражнения, повторное нажатие отменяет их выполнение.
Завершённые упражнения перемещаются вниз только визуально, исходный порядок сохраняется.
Во вкладке «Тренировка» изменение черновика записывается в localStorage. В редакторе изменяется состояние текущей сессии.

ВНИМАНИЕ: это виджет ВНУТРИ PWA, не системный виджет домашнего экрана iOS.
В папке iOS_WidgetKit_SOURCES находится пример исходников настоящего системного виджета.
Он не синхронизируется с веб-OSFIT без отдельного приложения-моста.

Сборка не подтверждена локально: нет установленных npm-зависимостей. Запустите npm ci && npm run build в Actions.
Перед установкой сохраните полную резервную копию JSON из OSFIT.
