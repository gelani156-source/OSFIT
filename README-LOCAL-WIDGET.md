# OSFIT 5.3 — локальный виджет с обратной отметкой

## Установка
1. Сохраните полный JSON-бэкап OSFIT прежде чем заменять файлы.
2. Загрузите архив в репозиторий OSFIT и опубликуйте GitHub Pages через GitHub Actions.
3. Создайте в Scriptable скрипт с точным названием `OSFIT Local Widget`, вставьте содержимое `OSFIT_Local_Widget_Scriptable.txt`.
4. Начните тренировку в OSFIT и нажмите `Передать тренировку в локальный виджет`.
5. Добавьте большой виджет Scriptable и выберите скрипт `OSFIT Local Widget`.
6. Коснитесь упражнения в виджете. Должен открыться OSFIT, где все подходы этого упражнения получат статус «выполнено» (или будет снят статус, если упражнение уже было выполнено).

## Важные ограничения
- Виджет Scriptable **не поддерживает настоящие интерактивные чекбоксы** как системные «Напоминания». Касание строки открывает ссылку на OSFIT, а не меняет рисунок на месте.
- Если ссылка откроет Safari, а OSFIT установлен как PWA с другим локальным хранилищем, OSFIT покажет ошибку отсутствующей тренировки. Ничего молча не изменится. Такой сценарий нельзя исправить локальной передачей URL без общей базы/сервера.
- Чтобы рисунок виджета отразил новую отметку, вернитесь в OSFIT и снова нажмите «Обновить виджет Scriptable»; автоматической обратной передачи нет.
- Синхронизация без облака и без файлов, но передача плана из OSFIT в Scriptable выполняется по явному нажатию; длинные планы ограничены длиной URL.
- Это прототип двустороннего локального обмена с указанными системными ограничениями, **не полноценная фоновая синхронизация**.
- ZIP составлен из OSFIT 5.2; сетевой `npm install` в текущем окружении не завершился. Поэтому успешный `npm run build` здесь не подтверждён.
