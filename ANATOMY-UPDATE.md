# OSFIT 5.5 — анатомический атлет

Заменена только отрисовка карты мышц на библиотеку body-muscles (Apache-2.0). Расчёты, программы, календарь, база и формат бэкапа не изменялись. Сохранены 7/30/90/365 дней, переключение перед/зад, интерактивное выделение и статистика.

## Установка
Обновить проект целиком, сохранив каталог `src` и структуру `public`/`.github`. GitHub Actions выполнит `npm install` и установит зависимость body-muscles. Не удалять PWA с iPhone и не очищать данные приложения.

## Проверка
Открыть экран «Атлет и мышцы», переключить ракурс, коснуться груди/спины/дельт и сравнить цифры с тренировочной историей. Новый пакет нуждается в проверке сборки GitHub Actions: локальный npm registry был недоступен.

## Особенности
Исходная библиотека содержит преимущественно мужской силуэт. Настройка пола OSFIT не меняется, но отдельный женский вариант анатомии пока отсутствует. Подсветка показывает относительную нагрузку; это не медицинская карта мышечной активности.
