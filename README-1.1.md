# Stack 1.1 — обновление

Разместите все файлы в корне существующего репозитория GitHub Pages с сохранением адреса и данных браузера. Не удаляйте приложение с домашнего экрана.

**Что нового:** голосовая запись (с альтернативой через диктовку клавиатуры), переключение темы без перезапуска, курсы USD/EUR от публичного зеркала ЦБ РФ, защищённая копия AES-256-GCM, проверка копий, напоминания.

**Ограничения:** распознавание голоса зависит от браузера/сетевых сервисов и не гарантировано в iOS PWA. Публичное зеркало курсов не является официальным доменом Банка России, хотя публикует его данные. Кнопка экспорта готовит файл, пользователь должен убедиться в его сохранении. PIN не шифрует IndexedDB. Нельзя восстановить пароль зашифрованной копии.

**Развёртывание:** GitHub Pages / Deploy from a branch / main / root, как в версии 1.0. Новая версия Service Worker применится после обновления вкладок. 

**Проверки:** `npm test` для существующих тестов, затем вручную пройти сценарии микрофона, тем, валют, шифрованного экспорта и восстановления на iOS Safari и установленной PWA.
